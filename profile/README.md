# just-did · 刚刚做了什么

极简跨端个人日报记录工具：随手记下「刚刚做了什么」，桌面端与手机端协同。

| 项目 | 说明 |
| --- | --- |
| 🖥️ [just-did-desktop](https://github.com/just-did/just-did-desktop) | 电脑端：本地记录 + 局域网 HTTP 同步服务（Qt/C++） |
| 📱 [just-did-app](https://github.com/just-did/just-did-app) | 手机端：随手记录 + 扫码推送电脑端（Kotlin/Compose） |

🌐 门户网站：[just-did.github.io](https://just-did.github.io/)
